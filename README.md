# tapcount-site

Static support and privacy policy pages for the TapCount app, served by GitHub Pages.

- Support: https://joooonny.github.io/tapcount-site/
- Privacy policy: https://joooonny.github.io/tapcount-site/privacy/

The app links to the privacy URL from `lib/util/links.dart` (`kPrivacyPolicyUrl`).
Keep that constant in sync if this repo or its paths are renamed.
